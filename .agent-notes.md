# Agent Notes

## Playwright MCP screenshot workaround
`playwright_browser_take_screenshot` fails with `EPERM: mkdir 'C:\Windows\.playwright-mcp'`.
Use `playwright_browser_run_code` instead:
```js
async (page) => { const buf = await page.screenshot({ type: 'png' }); return buf.toString('base64'); }
```
Then decode the base64 string. The `playwright_browser_evaluate` tool works for getting page HTML.

## Playwright MCP navigate workaround
`playwright_browser_navigate` also fails with the same mkdir EPERM error.
Use `playwright_browser_run_code` to navigate:
```js
async (page) => { await page.goto('https://...'); await page.waitForLoadState('networkidle'); return await page.title(); }
```

## Running the extractor against a live page
Inject the core extraction logic via `playwright_browser_evaluate` (using the `function:` parameter form).
The extractor uses `chrome.runtime.onMessage`, so you cannot eval `extractor.js` directly.
Copy just `SKIP_TAGS`, `INTERACTIVE_CURSORS`, `INTERACTIVE_ROLES`, `COLLECT_ATTRS`, and the helper
functions (`isVisible`, `shouldSkip`, `isInteractiveEl`, `isContainerVisible`,
`buildElementInfo`, `processElement`, `walkNode`) into a self-contained function.

## Running tests in WSL
The default `npm` in Git Bash points to the Windows-hosted npm (`/mnt/c/nvm4w/...`) which cannot
run inside WSL paths. Use:
```
wsl bash -c "cd /var/www/workshop/oira666/browser-agent/browser-agent-core && npm test"
```
The subagent runner automatically resolves this by using NVM-managed Node in WSL.

## mkdir in WSL from Git Bash
`mkdir -p //wsl.localhost/Debian/...` fails (read-only filesystem). Use:
```
wsl mkdir -p /var/www/workshop/oira666/browser-agent/tmp
```

## Image-only anchor link fix (github.com/explore)
GitHub Explore uses a card-layout pattern where each card has two `<a href>` elements pointing
to the same URL: a large image wrapper (no text, no aria-label) and a text heading link.
The extractor now filters out `<a href>` elements with no accessible label
(no text content, no `aria-label`, no `title`, and no child `<img alt>`).
Fix in: `browser-agent-core/content/extractor.js` — `hasAccessibleLabel()` + `processElement()`.
