You will receive a website
For each website please do the following:

1. Using your playwrite MCP exttract the full html (wait until the page is fully loaded)
2. Take a screenshot of the page
3. in the browser-agent core take the mechanism that walks aroung the DOM and extracts the interractable elements. Run this mechanism against the extracted html.
4. USE A SUBAGENT TO take the resulting json and evaluate it against the original html and the screenshot. Look if there are any missing interractable elements, that could be clicked / typed into, and if there are any duplications or other issues.
5. Fix the mechanism, that extacts the interactable elements, so that it extracts all interactable elements and no duplications.
6. Write a test that makes sure your fix works
7. USE A SUBAGENT to Run all the previous tests and make sure they pass. Do not delete or modify existing tests, unless there's clearly an error. Do not take shortcuts, go to the heart of the issue and fix.
8. When you are sure your change works and all the tests pass, commit your changes.

important: if you need to save any temporary files, use the /tmp directory in the project root. Remove them after you don't need them anymore. Make sure the tmp directory is in gitignore.

Do not duplicate the notes. Only write if it is really useful and novel and not obvious, if you had to really spend time to figure it out. Do not write simple obvious thinkgs. Only those that will really help your tammates to do the same job again. If you write any temporary scripts to execute the task, don't delete them and note in this file, so other agents can use them. Take care and help your teammates to do similar work more efficient and faster.
